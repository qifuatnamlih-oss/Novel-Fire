# NovelFire 🔥

NovelFire adalah platform web sederhana untuk membaca novel (Korea, China, dan Jepang) yang dibangun dengan HTML, CSS, dan JavaScript vanilla, serta menggunakan **Supabase** sebagai backend database dan autentikasi.

## Fitur Utama
- **Koleksi Novel:** Filter berdasarkan kategori negara dan penulis.
- **Mode Gelap:** Transisi tema yang halus dengan efek partikel.
- **Pencarian Real-time:** Cari novel berdasarkan judul, genre, atau penulis.
- **Sistem Bookmark:** Menyimpan bab terakhir yang dibaca secara otomatis.
- **Admin Dashboard:** Kelola konten novel dan bab langsung melalui antarmuka web.
- **Multi-bahasa:** Integrasi dengan Google Translate.

## Teknologi yang Digunakan
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Database & Auth:** Supabase
- **Icons:** Font Awesome
