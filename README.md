# NovelFire 🔥

NovelFire adalah platform web sederhana untuk membaca Fanfiction dan Novel (China, dan Jepang) yang dibangun dengan HTML, CSS, dan JavaScript vanilla, serta menggunakan **Supabase** sebagai backend database dan autentikasi.

## 🚀 Fitur Utama
- **Koleksi Novel:** Filter berdasarkan kategori negara dan penulis.
- **Mode Gelap:** Transisi tema yang halus dengan efek partikel.
- **Pencarian Real-time:** Cari novel berdasarkan judul, genre, atau penulis.
- **Sistem Bookmark:** Menyimpan bab terakhir yang dibaca secara otomatis.
- **Admin Dashboard:** Kelola konten novel dan bab langsung melalui antarmuka web.
- **Multi-bahasa:** Integrasi dengan Google Translate.
- **Responsif:** Tampilan yang optimal di perangkat seluler maupun desktop.

## 🛠️ Teknologi yang Digunakan
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Database & Auth:** [Supabase](https://supabase.com/)
- **Icons:** [Font Awesome](https://fontawesome.com/)

## ⚙️ Cara Instalasi

1. **Clone repositori:**
   ```bash
   git clone https://github.com/username/novelfire.git
   ```
2. **Konfigurasi Supabase:**
   - Buat proyek baru di [Supabase Dashboard](https://app.supabase.com/).
   - Jalankan query SQL yang disediakan (jika ada) di SQL Editor Supabase untuk membuat tabel.
   - Salin `URL` dan `Anon Key` dari pengaturan API Supabase.
3. **Pengaturan API:**
   - Masukkan kredensial Supabase Anda ke dalam file konfigurasi JavaScript proyek Anda.
4. **Jalankan Proyek:**
   - Buka file `index.html` menggunakan *Live Server* di editor kode Anda (seperti VS Code).
